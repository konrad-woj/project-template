# Proposed skills

Staging area for skills destined for the
[skillset repo](https://github.com/konrad-woj/skillset).

Skills are shared across projects and are never defined project-locally
(`CLAUDE.md`, "Skills"). `.claude/skills/` is vendored by `sync_skills.sh` and
gitignored, so a skill drafted here is moved to `skillset` and then arrives back
through the sync — it is not loaded from this directory.
